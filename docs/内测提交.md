## 版本说明（更新说明）

```
首个内测版本 0.5.2。

- 手机在同一 Wi-Fi 下扫码配对，即可用手机操作电脑上的 DeepSeek Harness
- 手机端显示完整的 DSH 界面：发指令、看实时输出、审批工具调用
- 电脑列表显示在线/离线，支持重命名与多台切换
- 支持横屏，自动避开状态栏、刘海与手势条
- 连不上时显示原因并自动重连
- 需要电脑端配套程序（开源，见下方测试说明）
```

## 测试说明（给测试者）

```
1. 电脑端（Windows）：
   - 安装 DeepSeek Harness 桌面端
   - 从 https://github.com/hk2thb78sw-afk/dsh-phone-bridge/releases 下载 dsh-phone-bridge 压缩包
   - 完全退出 DSH，双击「安装连接器.cmd」，再打开 DSH
   - 浏览器打开 http://127.0.0.1:4870/__phone/desktop 查看配对码

2. 手机端：
   - 手机与电脑连同一个 Wi-Fi
   - 打开 App，点右上角「+」，扫描电脑页面上的二维码
   - 配对成功后即可操作

3. 已知限制：
   - 必须同一局域网（手机用 4G/公司网时连不上）
   - 电脑睡眠时连不上
   - 没有后台通知
   - 配对后的手机等同于电脑本人的操作权限，请只在自己的电脑上使用
```
